# Player bows — planned inventory equipment

This folder is reserved for future player-usable bow items. R1 does not add a player bow or mix enemy definitions/art into this folder.

The Skeleton Archer’s bow definition lives under `ENTITIES/Species/Undead/Skeletons/Archer/Equipment/Bow/`, beside its Sprites artwork subfolder. Enemy/player equipment can reuse behavior without sharing item definitions or folders. Projectile mechanics stay under COMBAT/Projectiles.
