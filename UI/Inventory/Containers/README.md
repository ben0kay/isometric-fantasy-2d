# Shared Container and Loot UI — Planned

Reusable presentation for chests, barrels, corpses, storage furniture and other loot/storage interfaces. Share item cards, tooltips, sorting and transfer controls with the player backpack; container skins/layouts may differ. Data/stack ownership and transactional transfers belong to shared gameplay inventory/container systems, not these screens. Future Avalonia-authored containers should be configurable by Resources rather than per-container scenes. See `../PLAYER_INVENTORY.md`.

**Status:** Folder/documentation only.
