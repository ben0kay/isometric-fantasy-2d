# UI

Shared reusable visuals and gameplay interfaces. `Shared/Buttons/UIButtonFactory.cs` is the universal button factory with Resource-driven styling. `Menus/` contains the fantasy Boot and Main Menu entry flow. HUD/Gameplay now owns the UI1 nine-slot visual belt and UI2 non-pausing inventory composition; Inventory owns the reusable pack view. Actual item storage/binding, Crafting and Tooltips remain future work. See [UI1/UI2 validation](HUD/Gameplay/UI1_UI2_Validation.md).
