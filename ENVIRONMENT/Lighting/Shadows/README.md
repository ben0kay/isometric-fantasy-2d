# Sun shadows
SunShadowRenderer caches production sprites after scenery/wind setup. Shared silhouette materials preserve scale, mirror, offset and the sprite transform. Content data controls CastSunShadow and ContactShadowRadius; grass opts out. It updates projections from daylight and shared wind, never scans the scene each frame.

Art-directed flat-ground silhouettes do not occlude one another or climb terrain. More casters add draw/overdraw cost; dynamic registration is outside this fixed-world pass.

P3 stability: casters register/unregister with streamed chunk adapters. Cached conservative artwork reach plus current projection length rejects distant static casters before transform/material updates; off-screen casters remain active when their shadow can reach the prepared view. One camera rectangle is shared across the recursive renderer. Contact and projected nodes start hidden, disable interpolation and use world-space placement. Appearance changes invalidate extent caches. EnvironmentMasterConfig controls the common culling switch/margin; F7 reports total/updated casters and CPU projection time. This supersedes the fixed-world/dynamic-registration limitation above. Native local-light shadows remain a separate system.
