# ENVIRONMENT/Atmosphere/Fog

Reusable low-lying ground mist, volumetric-looking 2D layers, atmospheric haze and fog movement. Profiles may specify colour, height, density, softness, drift and camera/biome masking. A cursed forest can have white floor mist; a swamp can reuse the same renderer with different settings. Weather may influence the fog, but it does not own the fog shader.

> **Status:** Future architecture / folder placeholder only. No new production environmental mechanics are implemented in this folder.
