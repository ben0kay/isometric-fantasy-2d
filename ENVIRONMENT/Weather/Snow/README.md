# Snow
WorldSnow reads SnowProfile, progresses coverage/automatic accumulation or melt in real seconds, creates ground cover and the bounded 1300-flake WorldSnowfall GPU emitter, and updates shared content adapters. SetCoverage supports immediate developer scrubbing. Snow starts disabled; one master switch/coverage controls all compatible ground, tree, rock and grass surfaces. Falling snow and rate remain independently adjustable. Wind comes from the same source as rain and foliage.

Surface ownership: ground shaders are WORLD/Terrain/Ground/Surfaces/Snow; vegetation variants are WORLD/Content/Vegetation/Shared/Snow; boulder caps are WORLD/Content/Rocks/Snow. PlayerSnowVisual under ENTITIES/Player/Visuals/Surfaces is the sole shallow burial adapter; no liquid/wading code is copied.

Disabling snow restores vegetation/rock material identities immediately and clears ground cover. Removing the snow node also restores them and removes the optional player visual helper. Authored resources and the separate sun shadow cache remain intact. Colour/UV heuristics retain the proven green foliage/optional pink profile limitations; unrelated artwork may need a new mask/profile. No footprints, snow physics or seasons are implemented.

## Dormant snow contract — P0-A/P0-B

`SnowProfile.Enabled` is the independent snow master switch; rain remains controlled by its own profile. OFF immediately clears coverage, restores vegetation/rock materials (including inactive chunks), frees the snowfall emitter and stops WorldSnow processing. Positive snowfall requires Enabled, Snowfall and SnowfallRate > 0; rate zero or Snowfall=false frees all GPU flakes but can leave settled surface coverage. No probabilities or weather scheduler are implemented.

All SnowProfile setters emit Changed only on actual changes, so Inspector/F9 and a future weather controller wake sleeping systems directly. Coverage simulation runs only during transitions or automatic accumulation/melting; endpoints sleep. SetCoverage scrubs immediately. Existing cover is a single static world-bounded quad with world-space shading and normal viewport clipping, removing camera-follow mesh writes; settled cover still has rendering cost in view. New/re-entering chunks receive current coverage explicitly. Active snowfall retains a camera/wind callback but only rewrites bounds/motion when those inputs change; its budget remains 1300 GPU flakes. No snowfall node/resources are created while OFF.

Visible snow foliage registers shared wind followers and source-keyed wetness links, forwarding only actual changes without waking coverage or polling each tree. Zero snow unregisters those links; off-screen chunk suspension also detaches them until re-entry. Per-chunk adapter setup/material caches still exist for streaming lifecycle; the shared player surface helper still runs for liquid wading/burial and immediately rejects snow depth when disabled. This pass does not claim all environment/player work stops.

Validation: ValidateSnowSleeping passed 23 checks and covers default dormancy, master on/off/re-enable, zero rate, independent snowfall toggle, settled appearance/settings, synthetic camera canvas bounds, wind/wetness composition, inactive-chunk clearing, chunk lifecycle and automatic endpoints. ValidateRainSleeping (22 checks) and ValidateSceneryVisibility (167 checks) also passed. Local compiler/runtime: .NET 8 / Godot 4.5.1; project target 4.7.2, visible particle transitions and target-PC FPS/GPU remain unverified. No benchmark improvement is claimed.

## B1 layered blizzard snowfall

B1 is implemented, awaiting local visual validation. Above snowfall intensity 1, the resolved storm fades in soft far flakes, middle flakes, larger/faster foreground flakes and low blowing snow wisps. Normal 0–1 snowfall is unchanged. F9 → Environment → Snow → Blizzard has independent layer/spindrift switches, extra-flake budget, spindrift count and gust strength. Profile tuning lives in BlizzardProfile.tres; runtime edits are cloned. Default combined ceiling is 2600 flakes (1300 normal + 1300 partitioned storm) plus 64 wisps. The controller creates no optional visuals at zero, and frees the helper on storm/master shutdown. Active helper work is camera bounds plus throttled gust updates; per-flake motion is GPU-owned. [B1 scope, lifecycle and local checks](B1_Validation.md). B2 daylight/haze/visibility and B3 screen frost remain planned.
