# ENVIRONMENT/Wind/Visuals

Reusable render hooks/shaders for leaf/canopy sway, grass movement, particles and drifting mist. The world assets remain under WORLD; visual adapters consume environmental wind strength. Refer to `DEBUG/TopDownTest/Trees/TreeSway.gdshader` for a test of stationary roots and swaying canopy.

> **Status:** Future architecture / folder placeholder only. No new production environmental mechanics are implemented in this folder.
