# Combat fixtures

`ValidateCombatFoundation.tscn` runs C1 deterministic health/stats/damage and production player/entity integration. Run with Godot Mono headless after building. Exit 0 plus `C1 PASS` is success; any violated contract exits 1. No campaign storage is accessed. P4 save compatibility and player HP persistence are exercised separately in TESTS/Save. See COMBAT/C1_Validation.md for full results, commands and manual performance checks.

`ValidateMeleeExecution.tscn` runs C2 shared timing/stats/defense, moving geometry/misses, faction/self/friendly exclusion, walls, dense-query fail-closed behavior, actor death/suspension/queued-target safety, real Oak/Pink tool feedback, actual input→axe and skeleton→player adapters, and health-bar settling. It instantiates production components without a WorldScene or campaign and exits 1 on failure. See COMBAT/C2_Validation.md for exact commands, baseline save compatibility and broader regression limitations.

C2.5: `ValidatePlayerActions.tscn` checks actual starter item/profile selection, 11/5 axe and independent sword damage, cooldown switching rejection, normal armor and frontal/rear/unknown guard order, sprint override/release, dodge priority, hop body/collider/offset invariants and no immunity, death/suspension cleanup. `PlayerActionsPractice.tscn` is a disposable manual room: one 50-HP skeleton, real player controls and an explicit reset button; no saves or inventory. Skeleton Basic now also defaults to 50 HP in production. The sword is temporary SVG art; the blue guard arc is debug geometry. See COMBAT/C2_5_Validation.md for exact commands and remaining checks.

AC1: `ValidateActorCollision.tscn` checks canonical player/entity masks, swept player/entity and entity/entity blocking, static-wall blocking, removal, and campaign-arrival-style overlaps against actors and scenery. Exit 0 with `AC1 PASS: 11 checks` is expected. Added but not yet executed; see [AC1 commands/limitations](../../ENTITIES/Shared/Movement/ActorCollisionPlan.md). No campaigns are accessed.

AC2: `ValidateActorLifecycle.tscn` adds 17 intended checks for living/dead blocking, disabled-root physics removal/reactivation, stale enemy velocity, player death/restoration, retirement, hop invariants, and real walk/sprint/dodge into a wall. Added but not executed here; see [commands and limitations](../../ENTITIES/Shared/Movement/AC2_Validation.md).
