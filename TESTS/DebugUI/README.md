# Debug HUD checks

`ValidateDebugHud.tscn` instantiates the production World and checks exclusive category selection, future-category insertion, viewport resizing, fire controls under Environment, F9 hiding/restoring the selected drawer, hidden refresh sleep, live combat bindings and settings restoration on unload.

See [ES3/HUD validation](../../ENTITIES/Shared/Movement/ES3_Validation.md). Headless UI assertions do not establish graphical readability or mouse feel on Windows.
