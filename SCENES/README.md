# SCENES

Entry-point, test, and integration scenes will live here. A future basic debug playground can be organized here when gameplay implementation begins.

**Status:** Folder and blank configuration template only. No debug playground, ground, camera, or player scene has been created.

- `ScenesMasterConfig.cs`: empty Inspector-ready configuration resource template.
- `DefaultScenesConfig.tres`: blank instance for future scene-level settings.

Keep individual reusable creature or building scenes alongside their owning feature folders; this folder is intended for top-level scenes that combine systems.
