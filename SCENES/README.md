# SCENES — Production scene composition

**F5** launches `UI/Menus/Boot/BootScreen.tscn`, set in `project.godot`; profiles and Main Menu start durable P4 campaigns. F5 does **not** launch DEBUG.

Open [World/World.tscn](World/World.tscn) and press **F6** for a disposable streamed-world test scene without campaign saves. See [World README](World/README.md) for current controls, ownership, validation and config.

SO2's explicit actor/prop/chunk/preview roots are implemented and headless-tested; rendered Y-sort/seams and target-PC performance are not yet accepted. See [scene plan](World/scene%20organize.md) and [validation](World/SO2_Validation.md).

For isolated 2D experiments, open [DEBUG/TopDownTest](../DEBUG/TopDownTest/README.md) and press F6. Retired 3D terrain testing is [archived](../Notes/ARCHIVE_DONOTREADUNLESSINSTRUCTED/NATURAL_TERRAIN.md). Old courtyard scenes and `DEBUG/VisualTests/README.md` do not exist.
