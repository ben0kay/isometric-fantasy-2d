# SCENES

Reserved for future production entry-point/integration scenes. The two disposable courtyard tests and temporary Player scene now live in `DEBUG/VisualTests/`, alongside their SVG artwork.

Open `DEBUG/VisualTests/Courtyard3DProps.tscn` or `Courtyard2DProps.tscn` and press F6 after building C# in Godot .NET. F5 starts the 2D-prop test. See [debug instructions](../DEBUG/VisualTests/README.md).

The existing ScenesMasterConfig and default resource remain reserved; these authored tests do not need runtime scene settings.
