# Oak Forest
Biome.tres references the ForestGrass surface and canonical oak, boulder and grass content. Edit its inline populations to tune count, scale, mirroring and clustering. The resource owns no artwork or species-specific code.

Environment.tres contains optional component overrides. Atmosphere.tres starts with the familiar forest haze/particle settings; other components inherit the world fallback profile. Refer to ENVIRONMENT/Profiles/README.md for the data contract.
