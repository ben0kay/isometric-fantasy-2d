# Shared biome data
WorldBiomeDefinition holds identity, surface and ordered populations. BiomePopulation holds placement settings inline within a biome. Content resources remain canonical under WORLD/Content. No region topology or climate generation is implemented.

`WorldBiomeDefinition.Hydrology` optionally references `BiomeHydrologyProfile`. P5a/P5b applies hard freshwater lake/river permissions to biome assignment around preplanned water. Suitability 0–1 softly biases compatible site selection and growth (zero stays permitted if its hard flag allows it); null profiles allow both at weight 1. Impossible positive-weight biome sets fail without removing water. The legacy biome-first water API retains its earlier probability/endpoint interpretation for baseline tests only. Profiles remain authoring data, not managers or copied visuals. See [geography rules](../../Generation/World/Geography/README.md).

WG3 now consumes river permissions and suitability as well. Hard river exclusions apply to the whole final footprint; suitability weights endpoints and route cost. Null remains permissive. River terminal pools follow river permissions rather than being reclassified as separately generated lakes.
