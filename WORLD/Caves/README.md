# WORLD/Caves

The underground **world domain**, not a duplicate object library. Supports entrances, cave biome configurations and cave-specific regional features; underground generation algorithms live in `WORLD/Generation/Caves/`. Reuse rocks, mineral deposits, structures and animals from canonical `Content/` and `ENTITIES/` definitions.

> **Scaffolding only:** This folder currently contains documentation, not implemented world content or generation logic.
