# Plants

PL0 audited; PL1 foundation implemented (engine validation outstanding). PL2 artwork definitions and Oak biome populations have been authored; PL2 native serialization/visual checks are **awaiting local validation**. [Plan](PLANTS_IMPLEMENTATION_PLAN.md) · [PL0/PL1 audit and checks](PL0_PL1_Validation.md).

**One shared Plant.tscn**, **one VegetationDefinition Resource per distinct plant type**, and **one or more inline VegetationVisualVariant entries per Resource**. All eight `Definitions/plant_oak_001.tres` … `plant_oak_008.tres` now use the real PL1 exports (not staging metadata). Each has its own PNG under `Sprites/`, grounded source-pixel anchor, conservative visual bounds and stable `plant.oak.XXX` ID. All share `Plant.tscn` and one `PlantWind.tres` material using the existing wind shader. To give an individual plant multiple looks later, append more inline visual variants to *that same* .tres, not more scenes or separate species definitions.

Oak Forest `Biome.tres` explicitly references **all eight as separate BiomePopulation entries**. Each starts with streamed density 2.5 instances/million square world units, preview Count 12, and scale 0.55–0.80; per-population values can be tuned independently. Oak grass streamed density changes from 60 to 45, so Oak totals **102 per million** (26 oak, 11 rocks, 45 grass, 20 plants) within the existing 96-unit generator candidate capacity (~108.51). Pink Meadow and all existing grass/tree/rock content scenes and definitions are unchanged. Low-growing plants use inherited `GrassLike=true` placement metadata and snow vegetation response; their rooted placement and weather visuals require user visual validation.

**PL3 implemented — awaiting native/Windows validation:** normal World streaming and compatibility preview now consume Template + VisualVariants, choose seeded artwork and configure the shared Plant before publication. Eight Oak types spawn through the existing population settings; Pink remains unchanged. Open SCENES/World/World.tscn and press F6; no enable/connect step. Variant bounds/radii participate in spacing, chunk halos and camera margins. Existing wind/snow adapters bind at normal environment/chunk publication and detach on unload. [PL3 evidence and local checklist](PL3_Validation.md).

**Save compatibility:** modifying Oak's referenced biome/populations changes the campaign content fingerprint and may reject Continue for campaigns created with the old content. Local generator version is now 2 because previously skipped vegetation now materializes. Earlier local-generator saves are rejected by the existing compatibility check; no save migrations or overrides were made. Test on a new disposable F6 World / new campaign after PL3; retain existing saves.

**Performance:** authored Resources and one shared GPU wind material introduce no per-plant idle callbacks. PL1 VegetationInstance configures sprites once, then disables Process/PhysicsProcess. Local validation must verify streamed registration, return visits, weather activation/unload and target-PC FPS; no performance measurements are claimed here.
