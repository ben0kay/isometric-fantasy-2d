# Pink Blossom
PinkBlossom.tres is the shared TreeDefinition. Scene/art/material are byte-copied or minimally adapted from DEBUG PinkBlossom01: original rooted polygon, Sprite position (-68,-188), scale (0.85,0.90), mirror behaviour and wind response. No axe-hit/fire helpers are extracted.

The material references the existing production VegetationSway shader. Sprite snow_foliage_profile=1 uses the existing shared pink-foliage snow detection. Definition data enables canopy snow, contact/sun shadows and transition clearance. The biome only references this content definition.
