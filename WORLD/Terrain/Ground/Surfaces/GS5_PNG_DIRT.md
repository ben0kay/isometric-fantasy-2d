# GS5 grayscale dirt artwork

Dirt now uses `Textures/Dirt01_gs.png` (256×256), Recipe `GrayscaleArtwork` (3), instead of procedural Dust. Rock now reuses this PNG with a dull grey biome tint and the mineral mask family. The old-project adaptation document is historical for Dirt.

The shared streamed renderer uploads grayscale extra artwork to a separate nearest-filtered, non-mipmapped RGBA8 atlas. Each tile is copied at native 256×256 with no resize; identical texture references share a tile. Existing base and legacy artwork retain the original 32px atlas and sampling. The current one-tile upload is 256 KiB; atlas allocation scales with distinct configured grayscale textures, not chunks. No extra draw pass or frame callback. Default-off previews preload once; hidden/zero-opacity layers return before artwork sampling. F9 writes changed uniforms only.

Grayscale shading is `texture.r * 2 * Surface.BaseColour * layer.Tint`, blended using artwork alpha and the existing organic mask/opacity. Mid-grey is neutral. Dirt BaseColour is white; each biome sets its own dirt-layer Tint (Oak starts warm brown: 0.50, 0.36, 0.22). Reuse the profile/PNG across biomes without changing grass tint. MaterialFeatureSize controls repetition in world units, now 128 (previously 256), making source features half as large. Native grayscale source dimensions currently require 256×256; other recipes retain their existing contracts.

The broad Dust mask family is retained for grayscale Dirt: same world-space frequency, coverage threshold, warp, salt, softness and F9 multipliers. Oak coverage 0.4, opacity 1.0 (previously 0.8), patch size 500, softness 0.10, warp 0 and salt 431 retain their authored values except opacity. Layers remain OFF by default. Oak base/accompanying settings, ForestGrass and Pink are unchanged.

Save compatibility follows the existing narrow terrain migration pattern: exact current Oak/Pink/Dirt/Rock hashes gate reconstruction of the full previous dependency fingerprint from two frozen source files. Unrelated content differences still reject. No schema/world-ID/scenery changes.

Validation: run `python TESTS/Terrain/check_ground_shader_gl.py`. Mesa checks pass for unchanged pre-GS2 base output (maximum difference 0.0), all 256×256 synthetic source pixels/tint, solid interiors and a narrower broken transition, zero opacity, independent controls and negative-coordinate chunk seams. Static checks verify PNG dimensions, preserved authored mask fields and frozen migration sources. Godot fixtures now check byte-identical native PNG upload and the migration bridge.

## Dirt boundary refinement

After visual feedback, Oak dirt opacity is now 1.0 so patch interiors fully replace the grass. Broad placement, coverage, patch size, salt and texture scale remain unchanged. Grayscale extra layers use EdgeSoftness × 0.20 (previously × 0.12) for the narrow transition and two world-pixel-quantized noise samples to bite into either side of the broad boundary (clumps and fine flecks). Breakup fades out away from the boundary; those extra samples are skipped there and for full coverage. Other material recipes keep their old masks. Existing F9 opacity still fades the entire layer when deliberately reduced; reset restores the new authored full opacity, while visibility remains OFF.

Software checks verify a substantially smaller partial-blend area, solid grass/dirt regions and broken boundary regions in both directions, plus seams and unchanged grass. These checks do not establish visual acceptance. The exact-source-gated DirtEdgesOakBefore reference supports the preceding PNG revision without bypassing unrelated campaign content checks. Texture detail/scale is unchanged; assess it after viewing the solid soil.

## Finer soil and shared grey rock

Both Dirt and Rock now repeat the existing native 256×256 PNG over 128 world units. This changes feature scale, not the source image or broad patch size. The shared texture reference deduplicates to one existing 256 KiB atlas tile; no new artwork/import is required. Dirt uses GrayscaleArtwork (3), with the Dust threshold family. Rock uses GrayscaleMineral (4), retaining the Basalt/mineral threshold family, current coverage/opacity/patch-size/salt and F9 slot. Oak sets rock Tint to (0.36, 0.37, 0.38), a muted near-neutral grey. The soil source does not become individually drawn pebbles merely through tinting.

Grayscale boundaries now use 0.20 × authored EdgeSoftness, slightly softer than the previous 0.12 factor while preserving solid interiors and irregular edge breakup. No additional shader samples or CPU/frame callbacks were introduced. Both layers remain default OFF and independent in F9. Grass identity colour, accompanying grass, base artwork and Pink stay unchanged.

Additional Mesa checks passed: exact 128-unit repeat sampling, expected dull grey output from the same tile, increased but still narrow partial-blend edge area, preserved mineral broad threshold and negative-coordinate rock chunk seams. Use F9 A/B to compare dirt alone, grey rock alone, both and reset.

## Texture variants

Dirt now uses both Dirt01_gs.png and Dirt02_gs.png through the optional GroundSurfaceProfile.TextureVariants list. The list replaces Texture on grayscale extra layers; an empty list keeps the existing single-texture fallback. Maximum four native 256×256 entries; nulls, wrong dimensions and lists on non-grayscale recipes reject during setup. Texture can be null when a valid grayscale list is supplied. Existing base grass and Rock are unchanged; Rock still shares Dirt01 through its original Texture field.

The setup compiler deduplicates every referenced PNG in one world-owned native atlas and packs bounded variant indices/count/selection scale into two additional columns of the overlay table (11 total). The two unique textures currently occupy a 512×512 RGBA8 square atlas (1 MiB, shared by all chunks), versus 256 KiB for the former single tile. There are no new materials, draw passes, samplers, nodes, frame callbacks or slider-triggered texture rebuilds.

Only a visible nonzero grayscale layer with more than one variant samples the extra selection noise. The shader selects adjacent entries and smoothly blends their premultiplied colours/alpha using absolute pixel-snapped world coordinates, layer salt and VariantPatchSize. It uses one artwork sample on selection plateaus, up to two within a blend. Single-texture layers keep one artwork sample. Dirt coverage/edge breakup, 128-unit texture repeat, biome tint, default-off state and F9 controls are unchanged. Native GPU cost remains unmeasured.
