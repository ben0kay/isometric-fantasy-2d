# Biome ground tint — pre-GS2 addition

The biome Inspector now provides GroundStack → DefiningBaseGround → Tint. Select a reusable grass surface, then choose an opaque RGB tint here without editing that shared profile. White is neutral. Tint multiplies the complete surface after palette/artwork/detail composition, before existing Godot lighting. It colour-modulates the source, so a dark green source does not become arbitrary bright pink from a single multiplier. Existing Oak/Pink custom palettes remain unchanged for parity; consolidating them into one neutral source is a separate visual authoring decision.

The legacy preview binds primary/secondary tint uniforms once and blends with its existing boundary. The streamed renderer still resolves Surface through the GS1 adapter; when any biome has a non-white tint it builds one additional coarse RGBA-float texture (16 bytes per macro cell), bilinearly sampled in world coordinates. Neutral white worlds skip the tint map build/upload and conditional shader sample. CPU idle work remains zero; no per-chunk material, node or update callback is added. Tint GPU cost is unmeasured. Shader uniforms/branches still require target-renderer validation.

Base tint is functional now; optional overlay tints await GS3 rendering. Nothing adds a new F9 drawer. Inspector edits apply when the world is rebuilt/restarted, not live while running.
