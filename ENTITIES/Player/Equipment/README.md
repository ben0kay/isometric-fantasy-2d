# Shared player equipment adapter

C2.5 `EquippedTool` renders one held item and submits primary/alternate requests to one shared `AttackExecution`. `EquippedItemDefinition` references two independent attack profiles plus texture/grip/scale/rotation. Axe and sword share the adapter; only temporary starter selection references the two defaults. No per-weapon attack state machines or inventory.

Primary sweep now begins at the **existing held angle** (no instant backward-angle snap), eases into a short snapshotted wind-up, and then sweeps across the locked aim at the original contact time. The shared `AttackProfile.SweepWindupFraction` defaults to 0.16 of the attack duration (bounded to 40% of the pre-contact portion); zero restores the old instant start if deliberately selected. Alternate thrust quickly extends with a cubic ease-out, reaches maximum extension at the original contact sample and smoothly retracts. Starter axe/sword thrust reach **28/32 visual pixels** beyond the resting orbit (formerly 8/14). Rendering remains cosmetic and never creates impact feedback on misses. Timings/arc/reach/damage remain in COMBAT profiles. Existing `AxeConfig`/scene Config remains a compatibility source for Enabled/HandAnchor/OrbitRadius/AimSpeed; actual starter damage/timing now comes from item attack Resources, not its inherited legacy attack fields. The old HitQuery child/API remains for compatibility callers/tests.

Keys 1/2 select axe/sword; 3 toggles a separate shield flag. Shield starts off. Switching rejects during actions or outstanding attack cooldown, so it cannot bypass recovery. RMB routes to guard only when equipped, otherwise to a visual hop. The optional blue guard arc is debug geometry, not shield artwork. Starter selection/flag is temporary, resets to axe/shield-off on scene load and is not inventory or persisted equipment.

Attack physics wakes only for accepted swings/cooldowns and sleeps on completion/cancellation. The pre-swing angle, wind-up fraction and thrust pixels are captured once when the attack is accepted; no new timer, Tween, Node or idle callback was introduced. The existing mouse-facing render callback remains and also positions the held item during a hop. Death, disabled scene ownership and exit cleanly cancel/unsubscribe/dispose.
