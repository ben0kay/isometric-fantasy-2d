# ENTITIES / Player

This folder will contain the controllable player character and its player-specific resources.

**Status:** Folder and blank configuration template only. No player controller, sprite, animation, or playable scene has been implemented.

- `PlayerMasterConfig.cs`: empty Inspector-ready configuration resource template.
- `DefaultPlayerConfig.tres`: blank instance for future player-specific settings.

Future movement, visuals, inventory, and interaction features should be grouped into feature subfolders when they are actually needed. Prefer reusable entity components for behavior shared with NPCs or creatures.
