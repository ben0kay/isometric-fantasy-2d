# Roles / Archetypes

Roles represent **what an entity does or how it is equipped**: knight, guard, soldier, bandit, merchant, farmer, mage, witch, hunter, archer, shaman, etc.

A Human, Elf or Goblin could potentially share a `Mage` role while having different species attributes. The role can configure equipment, combat style, schedule, occupation, abilities or AI policy without creating `HumanKnight` and `ElfKnight` species copies.

Species-unique variants can still live under that species' eventual Variants/ directory; prefer reuse over duplicate scripts. **Status: placeholder only.**
